# FIKS Creative Website

Responsive static MVP based on the supplied PRD. Open `index.html` or serve this directory with a static server.

Before production, set `WHATSAPP_NUMBER` in `script.js`, replace the placeholder email, connect lead storage to Supabase, and add the production analytics snippet. Funnel events already use `window.dataLayer`.

Images in `assets/` were created for this website and are presented as concept projects, not client work.
